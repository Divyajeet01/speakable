Why your voice agent says “asterisk asterisk”

Your LLM returns markdown, currency and dates. Your TTS engine reads them literally and your caller hears gibberish. Paste anything below and see what it should say instead.

Use it in your own code

Same engine as this page, as a Python package. Zero dependencies, MIT.

pip install speakable

# in your agent, right before the TTS call
from speakable import normalize
await tts.say(normalize(llm_output))
